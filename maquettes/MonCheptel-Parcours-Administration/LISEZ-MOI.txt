MonCheptel — PARCOURS ADMINISTRATION : écrans SVG, liens et animations

SOURCE DES ÉCRANS : ce sont les SVG de la dernière exportation complète (archive des 3 blocs). Les retouches faites ensuite directement dans Figma
(logos, barres du bas, fond de connexion, couleurs de cartes, écrans ajoutés…) n'y sont PAS. Pour l'état actuel de ton fichier Figma, le plugin
« MonCheptel - Export des parcours (v43) » produit le même ZIP depuis la dernière version.

CONTENU
  ecrans/                   16 écrans web (1440 x 900) + 7 pop-up, en SVG (textes modifiables)
  index.html                aperçu de tous les écrans
  liens/liens-administration.txt   la carte de navigation : écran par écran, texte exact du bouton -> destination, type, animation
  liens/liens-administration.csv   la même table pour Excel (+ colonne « Statut »)
  liens/liens-administration.json  la même table pour un développeur
  liens/graphe-administration.mmd  le graphe des écrans (mermaid.live ; le menu latéral est omis du graphe : il relie tout)
  animations/                      RESUME-ANIMATIONS.txt, animations.csv, animations.json

MENU LATÉRAL : présent sur les 16 écrans, il relie Tableau de bord, Utilisateurs, Vétérinaires, Maladies, Conseils, Alertes et Statistiques.
LIENS « À VÉRIFIER » : certains boutons prévus par le plugin (Connexion admin, Enregistrer sur « Ajouter une maladie », Ajouter un conseil…) n'existent pas dans cette exportation ; ils sont listés à part.

DANS FIGMA
  1. Glisse les 23 SVG dans la page « 03 · Administration » (application de bureau), clic droit > Frame selection.
  2. Lance le plugin MonCheptel (Corriger tout) : il reconnaît les écrans par leur nom et pose ces liens et ces animations.
