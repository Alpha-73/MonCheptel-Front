MonCheptel — ANIMATIONS DU PARCOURS ADMINISTRATION
============================================================

Ce sont les animations que le plugin MonCheptel pose sur les liens (réglages Figma « Prototype ») :

  Navigation entre écrans (161 liens)   : Animation intelligente (Smart animate), 0,3 s, courbe ease-out
  Ouverture d'un pop-up (7 liens)     : Fondu (Dissolve), 0,2 s, ease-out ; le pop-up s'ouvre en superposition (Overlay)
  Remplacement d'un pop-up (1 lien)   : Fondu (Dissolve), 0,2 s (« Swap » : la confirmation est remplacée par le pop-up suivant)
  Fermeture d'un pop-up (9 liens)     : action « Fermer la superposition » (Close), sans transition

Réglages de TOUS les pop-up :
  Position : centré · Fond : noir, opacité 35 % · Fermeture : au clic à l'extérieur du pop-up

Minuteries (passage automatique) : aucune dans ce parcours (la seule minuterie du projet est celle du splash : 3 s vers le choix du profil).
Survols : aucun.

Écrans du parcours : 16 écrans web (1440 x 900) + 7 pop-up (600 px de large).
L'écran « Admin - Connexion » (créé ensuite dans Figma) n'est pas dans cette exportation : voir la section « à vérifier » de liens/liens-administration.txt.
