MonCheptel — ANIMATIONS DU PARCOURS VÉTÉRINAIRE
============================================================

Ce sont les animations que le plugin MonCheptel pose sur les liens (réglages Figma « Prototype ») :

  Navigation entre écrans (37 liens)   : Animation intelligente (Smart animate), 0,3 s, courbe ease-out
  Ouverture d'un pop-up (4 liens)     : Fondu (Dissolve), 0,2 s, ease-out ; le pop-up s'ouvre en superposition (Overlay)
  Remplacement d'un pop-up (0 lien)   : Fondu (Dissolve), 0,2 s (« Swap » : la confirmation est remplacée par le pop-up suivant)
  Fermeture d'un pop-up (1 liens)     : action « Fermer la superposition » (Close), sans transition

  Lien vers l'autre page (1)           : « Ouvrir le prototype », nouvel onglet (Figma ne relie pas deux pages)

Réglages de TOUS les pop-up :
  Position : centré · Fond : noir, opacité 35 % · Fermeture : au clic à l'extérieur du pop-up

Minuteries (passage automatique) : aucune dans ce parcours (la seule minuterie du projet est celle du splash : 3 s vers le choix du profil).
Survols : aucun.

Écrans du parcours : 9 écrans mobiles (402 x 874) + 4 pop-up (354 px de large).
